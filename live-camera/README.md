# Live Camera

WebRTC live camera prototype using Node.js, Express and Socket.IO.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run:

   npm install
   npm start

4. Open http://localhost:3000

## Render

Build command:
npm install

Start command:
npm start

This prototype does not yet include Firebase authentication/password protection or a TURN server.
